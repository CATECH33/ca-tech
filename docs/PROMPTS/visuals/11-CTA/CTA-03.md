# CTA-03 — Partnership

## OBJECTIVE

Représenter la relation client-partenaire dans sa dimension de proximité et de confiance.
"CA-TECH est là avec vous." Chaleureux (dans la limite de la palette), accessible, professionnel.

## USE CASE

- Variante CTA si contexte "prise de contact" / "discutons ensemble"
- Section "Contactez-nous"
- Visual accompagnant le formulaire de contact

## PROMPT

```
two professionals in conversation at minimal dark table, seen from slightly above and behind,
only hands and arms visible on table surface, documents or laptop between them,
body language: one explaining, one listening, engaged mutual attention,
architectural premium meeting space, cold indirect lighting from above,
deep navy materials throughout, premium textures,
authentic documentary moment, not staged performance,
positive tension of productive conversation,
shot on Sony A7R V, 50mm, f/2.8,
--ar 3:2 --style raw --v 7 --q 2
--no faces looking at camera, handshake photo, generic boardroom, colorful materials, purple, neon
```

## VARIANTE — Seul le contact

```
single hand extending toward camera as if offering help,
dark navy background, cold natural light from left,
hand: professional, clean, confident gesture,
tight crop: hand and immediate wrist area only,
no props, no context — pure gesture of reaching out,
--ar 3:2 --style raw --v 7 --q 2
```

## NEGATIVE CONSTRAINTS

- Pas de poignée de mains frontale (cliché absolu)
- Pas de sourires dirigés vers l'objectif
- Pas d'environnement de réunion générique
- La confiance doit être dans le langage corporel, pas la performance

## ASPECT RATIO

`--ar 3:2` — 1200×800 px

## EXPECTED COMPOSITION

```
[Vue légèrement plongeante sur table et deux personnes]
[Seuls mains/avant-bras et table visibles]
[Documents/laptop entre eux]
[Grande zone sombre de chaque côté = texte CTA possible]
```

## COLOR DIRECTION

- Table : Deep Navy / pierre noire
- Matériaux : Tous dans la palette CA-TECH
- Lumière : Cold overhead indirect

## NOTES

Cette image est la plus "humaine" de la section CTA. À choisir si le message
de la section est "contactez-nous" plutôt que "commencez maintenant".

# DIGITAL-05 — Multi-Device Platform

## OBJECTIVE

Montrer qu'une solution CA-TECH fonctionne sur tous les devices.
Composition "ecosystem" : laptop + tablet + mobile dans la même scène.
Cohérence visuelle entre les trois appareils.

## USE CASE

- Feature "Compatible tous supports"
- Section responsive design
- Présentation globale de l'offre digitale

## PROMPT

```
three dark premium devices arranged on minimal dark surface: laptop open left,
tablet propped center, smartphone standing right, all screens on,
all displaying coordinated dark minimal interface (same abstract layout, different format),
cold blue accent consistent across all three screens,
devices: all dark aluminum/glass, no brand markings,
arrangement: slight perspective creating depth, right side recedes,
overhead and front combined view angle, 3/4 perspective,
editorial technology product photography,
shot on Sony A7R V, 50mm, f/5.6,
--ar 16:9 --style raw --v 7 --q 2
--no Apple/Samsung logos, colorful UI, white background, consumer setup, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas de logos de marque sur les appareils
- L'interface sur chaque écran doit être cohérente (même "look")
- Pas de fond clair
- Arrangements symétrique à éviter (créer une légère asymétrie dynamique)

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[Laptop gauche, légèrement en retrait]
[Tablet centre, propped up (le plus net)]
[Smartphone droit, se rapprochant du bord frame]
[Perspective fuyante vers la droite]
[Desk sombre, cold screen glow sur surface]
```

## COLOR DIRECTION

- Appareils : Dark aluminum / Space Black
- Screens : Dark navy UI + `#359BD9` accent cohérent
- Surface : `#05101E`

## CAMERA / LENS

Sony A7R V — 50mm — 3/4 angle — f/5.6

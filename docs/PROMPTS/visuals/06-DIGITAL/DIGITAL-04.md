# DIGITAL-04 — E-commerce Platform

## OBJECTIVE

Représenter une expérience e-commerce premium. L'accent est sur la qualité de l'interface
et la fluidité de l'expérience d'achat, pas sur un produit spécifique.

## USE CASE

- Section "Création de boutiques en ligne"
- Showcase e-commerce
- Feature "checkout et conversion optimisés"

## PROMPT

```
dark premium e-commerce checkout page on laptop screen, minimal modern UI visible,
screen content: abstract product card with single elegant product silhouette and clean button,
no price, no text readable, purely visual suggestion of purchase flow,
laptop on dark desk, hand near trackpad ready to click,
cold blue accent on checkout button element visible on screen,
focused composition showing the decisive moment before purchase,
editorial technology photography,
shot on Sony A7R V, 85mm, f/2.8,
--ar 3:2 --style raw --v 7 --q 2
--no Shopify interface, generic product photos, shopping cart icon obvious, colorful UI, purple, neon
```

## NEGATIVE CONSTRAINTS

- Interface e-commerce abstraite — pas Shopify / WooCommerce reconnaissable
- Produit à l'écran doit être une silhouette abstraite (pas un vrai produit)
- Pas de panier ou icône e-commerce cliché
- Main optionnelle : si présente, posture naturelle (pas dramatique)

## ASPECT RATIO

`--ar 3:2` — 1200×800 px

## EXPECTED COMPOSITION

```
[Laptop légèrement angled]
[Écran : product card abstracte + bouton accent bleu]
[Main optionnelle sur trackpad]
[Desk sombre, cold ambient]
```

## COLOR DIRECTION

- Screen UI : Dark navy avec accent `#359BD9` sur CTA
- Laptop : Dark aluminum
- Fond : Deep Navy / surface noire

## CAMERA / LENS

Sony A7R V — 85mm — f/2.8

# DIGITAL-02 — Dashboard / Data Interface

## OBJECTIVE

Un dashboard premium affiché sur un grand écran. Données visuelles, KPIs, graphiques.
L'interface est abstraite mais communique "données maîtrisées, décisions éclairées".

## USE CASE

- Section "Applications sur mesure"
- Feature "Dashboard et analytics"
- Cas d'usage e-commerce / gestion

## PROMPT

```
widescreen monitor displaying dark premium analytics dashboard,
screen content: minimal grid with abstract chart shapes and data blocks,
no readable numbers or text, pure layout suggestion,
dark navy UI theme on screen, cold blue accent on one graph element,
monitor: dark bezeled, professional grade,
screen placed on minimal desk, cold ambient light from screen illuminating desk edge,
shot slightly below screen level looking up at display,
editorial technology photography, product focus,
shot on Sony A7R V, 85mm, f/4,
--ar 16:9 --style raw --v 7 --q 2
--no readable data, colorful charts, Excel look, consumer monitor, purple, neon, HubSpot interface
```

## NEGATIVE CONSTRAINTS

- Pas de données lisibles (chiffres, noms)
- Pas de graphiques colorés (barres arc-en-ciel)
- Pas d'interface reconnaissable (Excel, Google Analytics, HubSpot)
- Pas d'écran blanc ou light theme

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[Écran centré ou tiers gauche]
[Dashboard abstrait : 4-6 blocs de données visibles]
[Moniteur légèrement incliné ou vu légèrement de dessous]
[Desk edge visible en bas, screen glow sur surface]
```

## COLOR DIRECTION

- UI : Dark navy `#102740` avec accent `#359BD9` sur élément principal
- Moniteur : Anthracite / black
- Éclairage ambiant : screen glow uniquement

## CAMERA / LENS

Sony A7R V — 85mm — f/4 — angle légèrement bas (contre-plongée)

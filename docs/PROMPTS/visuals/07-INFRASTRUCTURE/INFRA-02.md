# INFRA-02 — Distributed Network

## OBJECTIVE

Représenter un réseau distribué : plusieurs nœuds qui communiquent sans point central unique.
Robustesse, redondance, fiabilité.

## USE CASE

- Feature "Haute disponibilité"
- Section "Architecture distribuée"
- Présentation infrastructure client

## PROMPT

```
macro photograph of dark circuit board from extreme angle, components as city skyline,
capacitors and chips forming architectural landscape,
cold blue LED traces like street lights running between components,
deep depth of field compression, long telephoto macro,
monumental scale effect: components look like buildings,
no text or labels visible, purely visual abstraction,
industrial elegance, engineering precision,
shot on Sony A7R V, 200mm macro, f/16,
--ar 16:9 --style raw --v 7 --q 2
--no green PCB, colorful components, obvious brand chips, text on board, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas de circuit imprimé vert (trop "computing générique")
- Pas de labels ou textes sur les composants
- Fond de circuit doit être sombre (noir ou navy) pas vert standard
- Les composants comme bâtiments — l'angle est essentiel

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[Vue rasante sur circuit (quasi-horizzontal)]
[Composants s'élèvent comme buildings à l'horizon]
[Traces LED = réseau lumineux au sol]
[Profondeur extrême grâce à la compression téléphoto]
```

## COLOR DIRECTION

- PCB : Dark navy / black (pas vert)
- Traces : Cold blue lumineux
- Composants : Silver / anthracite

## CAMERA / LENS

Sony A7R V — 200mm macro avec extension tube — f/16

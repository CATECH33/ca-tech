# INFRA-03 — Security / Cybersecurity

## OBJECTIVE

Représenter la sécurité dans l'infrastructure numérique. Solide, invisible, protecteur.
Éviter tous les clichés "cadenas sur fond bleu" ou "code vert matriciel".

## USE CASE

- Feature "Sécurité et conformité"
- Section "Protection des données"
- Présentation RGPD / certifications

## PROMPT

```
close-up of precision combination lock mechanism, internal structure exposed,
dark matte metal housing, cold blue internal illumination of pin mechanism,
extreme macro showing the complexity of simple security device,
deep black background, single cold light source from left,
no keyhole visible, no padlock shape, internal mechanism only,
industrial precision photography, watchmaking aesthetic,
shot on Sony A7R V, 100mm macro, f/8,
--ar 1:1 --style raw --v 7 --q 2
--no padlock icon, shield icon, cyber cliche, green code matrix, hacker aesthetic, purple, neon
```

## VARIANTE — Sceau / Certification

```
single wax seal or metal embossing stamp pressed into dark material,
cold light from side revealing texture and depth of impression,
no readable text on seal, abstract geometric pattern only,
premium artisan craftsmanship meets digital security,
--ar 1:1 --style raw --v 7 --q 2
```

## NEGATIVE CONSTRAINTS

- Pas de cadenas iconique
- Pas de code vert "hacker"
- Pas de bouclier
- La sécurité doit être évoquée par la précision mécanique, pas les symboles

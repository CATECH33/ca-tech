# INFRA-01 — Cloud Architecture

## OBJECTIVE

Représenter une infrastructure cloud de manière premium et abstraite.
Pas des photos de data centers génériques. Quelque chose qui évoque la scalabilité
et la fiabilité sans montrer des serveurs physiques banals.

## USE CASE

- Section "Infrastructure et hébergement"
- Feature "Scalabilité et performance"
- Page services techniques

## PROMPT

```
aerial night photography looking down at city grid seen from extreme altitude,
street lights form precise geometric network patterns on dark earth,
suggests distributed network nodes from above, urban infrastructure as metaphor,
cold white and blue city lights, deep black voids between blocks,
no clouds obstructing view, perfect clear night,
abstract but real photography aesthetic,
minimal composition, 1/3 city lights 2/3 dark sky above,
editorial travel/aerial photography,
shot from aircraft, 50mm equivalent, f/8,
--ar 16:9 --style raw --v 7 --q 2
--no obvious data center, server rack, generic cloud icon, colorful city, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas d'icône "cloud" cliché
- Pas de serveurs rack physiques
- La métaphore urbaine doit être claire mais pas trop littérale
- Zone du ciel sombre = espace pour texte

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[Horizon: 1/3 bas = grille lumineuse urbaine]
[2/3 haut = obscurité / "le cloud"]
[Profondeur : ville s'étendant jusqu'à l'horizon]
[Zone supérieure : texte possible]
```

## COLOR DIRECTION

- Lumières urbaines : Cold white + pale blue
- Vides entre blocks : Near-black `#020508`
- Ciel : `#05101E` profond

## CAMERA / LENS

Simulation aérienne haute altitude — longue focale

# AUTOMATION-02 — Connected Business Systems

## OBJECTIVE

Représenter des systèmes d'entreprise interconnectés. CRM, email, données, notifications —
tout est relié. Image abstraite qui évoque la connectivité sans recourir aux icônes d'apps.

## USE CASE

- Feature "Intégrations et connexions"
- Slide MCP / API connections
- Présentation partenaires technologiques

## PROMPT

```
dark surface with multiple small precision instruments connected by fine metallic cables,
arranged in circular hub-and-spoke pattern, central element slightly elevated and illuminated,
brushed metal enclosures, cold blue indicator lights on each connected node,
cables organized and elegant, not chaotic,
top-down architectural composition,
deep navy background, precise studio lighting,
no logos, no brand text, abstract technical elegance,
editorial product photography,
shot on Sony A7R V, 50mm overhead, f/8,
--ar 3:2 --style raw --v 7 --q 2
--no logos, app icons, text labels, chaotic cables, colorful elements, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas de logos d'applications (Slack, HubSpot, Notion...)
- Pas de câbles emmêlés ou désorganisés
- L'élément central doit clairement dominer
- Pas de fond blanc ou clair

## ASPECT RATIO

`--ar 3:2` — 1200×800 px

## EXPECTED COMPOSITION

```
[Centre : hub principal légèrement surélevé]
[Rayonnant vers 5-6 nœuds en périphérie]
[Câbles réguliers et symétriques]
[Fond Deep Navy, lumière froide overhead]
```

## COLOR DIRECTION

- Hub central : Silver + cold blue light
- Nœuds : Dark metal, indicateurs LED `#359BD9`
- Câbles : Dark silver / anthracite
- Fond : `#05101E`

## CAMERA / LENS

Sony A7R V — 50mm — overhead — f/8

## LIGHTING

Panneau overhead cold. Spot doux sur hub central.

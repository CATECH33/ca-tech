# AUTOMATION-01 — Workflow Orchestration

## OBJECTIVE

Représenter visuellement un workflow orchestré. Plusieurs éléments fonctionnent ensemble
de manière fluide et automatique. Pas un diagramme — une image qui SUGGÈRE l'orchestration.

## USE CASE

- Slide showcase section Automatisation homepage
- Feature principale "Workflows automatisés"
- Présentation outils No-Code / automation

## PROMPT

```
top-down flat lay of precision mechanical clockwork components, perfectly aligned gears
of different sizes arranged in flowing connected sequence,
deep navy polished surface, each gear a different scale connected to the next,
cold blue light from single overhead source casting precise geometric shadows,
ultra minimal composition, perfect spacing between elements,
suggestion of movement and sequence through composition,
no digital screens, no text, purely mechanical metaphor,
editorial product photography, architectural overhead,
shot on Sony A7R V, 50mm overhead, f/11,
--ar 16:9 --style raw --v 7 --q 2
--no flowchart, arrows, text labels, digital screens, circuit board, generic automation icons, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas de flèches directionnelles visibles
- Pas de labels ou textes sur les éléments
- Pas d'écrans ou interfaces dans la composition
- La séquence doit être naturellement lisible (grand → petit → grand)

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[Vue overhead légèrement inclinée]
[Séquence d'engrenages diagonalement de gauche en bas à droite en haut]
[Espacement précis, composition respirante]
[Fond Deep Navy, ombres nettes]
[Zone droite supérieure : espace négatif pour texte]
```

## COLOR DIRECTION

- Engrenages : Brushed silver + dark metal
- Fond : Deep Navy `#05101E`
- Lumière : Cold white, ombres bleues

## CAMERA / LENS

Sony A7R V — 50mm — overhead — f/11

## LIGHTING

Panneau studio overhead unique. Ombres précises et orientées.

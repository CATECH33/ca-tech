# AUTOMATION-05 — Human → Automation → Result

## OBJECTIVE

Raconter la transformation : avant, la tâche était manuelle. Après, elle est automatisée.
L'image capture le moment de la transition, ou le résultat de la transformation.

## USE CASE

- Hero de la page Automatisation
- Slide "Avant / Après" dans une présentation
- Illustration du ROI de l'automatisation

## PROMPT

```
split-composition: left side shows single hand writing on paper with pen (warm light),
right side shows same hand resting still on desk with screen glow taking over (cold blue light),
dividing line is soft and natural (light transition, not hard cut),
dark premium desk surface, architectural composition,
both sides share same desk and context, time has passed between them,
documentary photography aesthetic, editorial,
shot on Sony A7R V, 50mm, f/4,
--ar 16:9 --style raw --v 7 --q 2
--no before/after text labels, split screen graphic, digital effects, cartoon, purple, neon
```

## VARIANTE — Résultat seul

```
professional leaning back in chair looking at clean results on monitor,
posture relaxed and satisfied, face not visible,
multiple screens showing organized data, no chaotic alerts,
cold blue ambient, deep navy office,
editorial portrait of a "problem solved" moment,
--ar 16:9 --style raw --v 7 --q 2
```

## NEGATIVE CONSTRAINTS

- Pas de labels "Before / After" dans l'image
- Pas de flèches de direction
- La narration doit être visible sans explication
- Pas d'effet de composition split-screen graphique trop artificiel

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[Tiers gauche : main / stylo / papier (lumière légèrement plus chaude)]
[Transition douce au centre]
[Tiers droit : main au repos / glow écran (lumière froide)]
[La transformation se lit de gauche à droite]
```

## COLOR DIRECTION

- Gauche : légèrement plus chaud (contraste intentionnel — unique exception palette)
- Droite : cold blue, Deep Navy
- Transition : gradient naturel de lumière

## CAMERA / LENS

Sony A7R V — 50mm — f/4

## LIGHTING

Deux sources : lumière chaude discrète côté gauche (lampe bureau), lumière froide screen côté droit.

## NOTES

Unique exception à la règle "pas de chaleur" : la lumière légèrement chaude à gauche
est INTENTIONNELLE pour renforcer le contraste "avant automation" vs "après automation".
Le tiers droit doit retrouver la palette CA-TECH standard.

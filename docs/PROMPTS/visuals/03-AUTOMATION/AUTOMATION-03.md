# AUTOMATION-03 — CRM Automation

## OBJECTIVE

Représenter l'automatisation CRM : données clients qui circulent, leads qui progressent,
contacts qui reçoivent le bon message au bon moment. Concret mais sans être littéral.

## USE CASE

- Feature "Automatisation CRM / HubSpot"
- Section No-Code automation
- Cas d'usage client type

## PROMPT

```
close-up of professional's hands reviewing printed contact cards arranged in systematic order,
dark desk surface, cold overhead light,
cards organised in clean rows suggesting a pipeline or funnel,
no text readable on cards, abstract printed content,
premium stationery feel, precision arrangement,
brushed metal ruler or alignment guide visible at edge,
editorial still life, controlled depth of field,
shot on Sony A7R V, 85mm, f/2.8,
--ar 3:2 --style raw --v 7 --q 2
--no digital screens, HubSpot logo, Salesforce, visible text, generic office, purple, neon
```

## VARIANTE — Abstrait digital

```
dark screen showing abstract flowing cards in grid, no readable content,
cold blue interface glow, minimal UI, systematic arrangement,
consultant hand pointing at screen (blurred) in foreground,
editorial technology photography,
--ar 3:2 --style raw --v 7 --q 2
```

## NEGATIVE CONSTRAINTS

- Pas de logos CRM reconnaissables
- Pas de texte lisible (noms, emails)
- Pas de sourire "customer service"
- Abstraction nécessaire pour éviter toute confusion avec des vraies données

## ASPECT RATIO

`--ar 3:2` — 1200×800 px

```
[Mains au premier plan, légèrement floues]

[Fond desk Deep Navy]
[Lumière overhead froide, ombres nettes]
```

- Desk : Deep Navy
- Lumière : Cold white

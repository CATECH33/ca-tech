# AI-03 — LLM Interface Environment

## OBJECTIVE

Un espace de travail où l'interface LLM est l'élément central. On voit l'écran,
on sent l'intelligence, mais sans montrer de texte lisible ni d'interface reconnaissable.

## USE CASE

- Card "Loïc IA" ou feature highlight interface
- Slide showcase section IA
- Contexte "assistant conversationnel"

## PROMPT

```
dark premium desktop workstation, widescreen monitor displaying minimal interface,
screen content deliberately blurred or abstract (cool blue glow, no readable text),
cold screen illumination casting long shadows on brushed aluminum desk,
premium mechanical keyboard in foreground, slightly out of focus,
clean cable management visible, professional dark studio workspace,
monochromatic blue-navy color scheme, controlled lighting,
editorial still life photography,
shot on Sony A7R V, 85mm, f/2.8,
--ar 3:2 --style raw --v 7 --q 2
--no readable text on screen, visible UI chrome, generic office, purple, neon, lens flare
```

## NEGATIVE CONSTRAINTS

- Pas de texte lisible sur l'écran
- Pas d'interface reconnaissable (pas de Chrome, pas de Windows)
- Pas de setup "gaming" (RGB, backlit keyboard arc-en-ciel)
- Fond de bureau personnel ou encombré = exclu

## ASPECT RATIO

`--ar 3:2` — 1200×800 px

## EXPECTED COMPOSITION

```
[Écran centré ou tiers gauche, légèrement flou]
[Clavier premier plan, net, 1/3 bas du frame]
[Lumière froide depuis l'écran illumine l'environnement]
[Espace droit sombre disponible pour overlay texte]
```

## COLOR DIRECTION

- Screen : glow `#359BD9` diffus, ambiance froide
- Desk : sombre, brushed metal ou verre
- Clavier : anthracite / dark silver

## CAMERA / LENS

Sony A7R V — 85mm — f/2.8 — ISO 800

## LIGHTING

Écran comme source primaire. Lumière ambiante minimale depuis gauche (hors cadre).

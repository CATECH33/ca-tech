# AI-02 — AI Agent (Autonomous Process)

## OBJECTIVE

Représenter visuellement un agent IA autonome : quelque chose qui pense et agit seul.
Pas de robot, pas de cerveau. Une machine intelligente abstraite mais reconnaissable.

## USE CASE

- Showcase Loïc IA section homepage
- Page dédiée agents IA
- Présentation des capabilities d'automatisation intelligente

## PROMPT

```
dark precision instrument seen close-up, complex internal mechanism with fine gears
and cold blue light nodes, mechanical intelligence without face,
microscopic engineering precision, deep navy metal housing,
cold blue illumination from within the mechanism,
technical macro photography, extreme detail in central zone,
bokeh edges, dark architectural negative space,
no human resemblance, purely technical and beautiful,
hyperrealistic product photography, premium Swiss watchmaking aesthetic meets digital,
shot on Sony A7R V, 100mm macro, f/4,
--ar 1:1 --style raw --v 7 --q 2
--no robot face, humanoid, brain, skull, generic circuit board, purple, neon, hologram
```

## VARIANTE — Logicielle

```
abstract network of processing nodes on dark surface,
geometric precision, cold blue electrical connections between 7-9 distinct nodes,
signal flow visible as thin luminous lines,
scientific data visualization aesthetic,
no text, no labels, pure structure,
--ar 1:1 --style raw --v 7 --q 2
```

## NEGATIVE CONSTRAINTS

- Pas d'anthropomorphisme (yeux, bouche, tête)
- Pas de circuit imprimé générique vert
- Pas de cerveau, neurone, synapse cliché
- La beauté doit venir de la précision, pas des effets lumineux

## ASPECT RATIO

`--ar 1:1` — 1200×1200 px (polyvalent, utilisable en card ou square)

## EXPECTED COMPOSITION

```
[Centre : mécanisme/nœud principal — net, précis]
[Rayonnement depuis le centre vers les bords (flou progressif)]
[Fond : Deep Navy profond]
[Zones de négatif symétriques (usage square prévu)]
```

## COLOR DIRECTION

- Structure : Silver / Dark Metal
- Lumière interne : `#359BD9` cold blue
- Fond : `#05101E` Deep Navy

## CAMERA / LENS

Sony A7R V — 100mm macro — f/4 — ISO 400
Profondeur de champ sélective : centre net, bords flous

## LIGHTING

Lumière interne à la structure uniquement. Pas de studio visible.
Effet : la machine émet sa propre lumière = intelligence.

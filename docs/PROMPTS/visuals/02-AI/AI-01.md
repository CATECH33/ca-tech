# AI-01 — Human + AI Interaction

## OBJECTIVE

Représenter l'interaction naturelle entre un professionnel et un outil IA.
Situation concrète, pas métaphysique. L'IA est là, elle répond, elle aide.

## USE CASE

- Slide showcase section IA homepage
- Page services IA / Loïc
- Visuels commerciaux

## PROMPT

```
professional's hands on premium keyboard, dark monitor screen above frame edge,
cold blue screen light casting soft gradient on hands and desk surface,
thin chat interface glow barely visible on screen reflection on desk,
minimal premium workspace: dark desk, brushed metal accessories, no clutter,
extreme close-up of hands, keyboard slightly blurred foreground,
screen detail in bokeh above,
architectural negative space left side for text overlay,
hyperrealistic editorial photography,
shot on Sony A7R V, 85mm macro, f/2.0,
--ar 3:2 --style raw --v 7 --q 2
--no face, stock photography, hologram hands, glowing text flying, corporate office, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas de visage
- Pas de texte lisible sur l'écran
- Pas d'interface flottante au-dessus des mains
- Pas de "typing dramatically" énergie générique

## ASPECT RATIO

`--ar 3:2` — 1200×800 px

## EXPECTED COMPOSITION

```
[Premier plan : mains sur clavier, net]
[Fond supérieur : screen edge en bokeh]
[Lumière froide : venant du haut (screen) illuminant les mains]
[Gauche : espace sombre pour texte]
```

## COLOR DIRECTION

- Mains : éclairées par lumière froide bleue
- Desk : Deep Navy / bois sombre ou verre
- Screen glow : `#359BD9` à très basse intensité

## CAMERA / LENS

Sony A7R V — 85mm macro — f/2.0 — ISO 800

## LIGHTING

Screen comme seule source de lumière. Ambiance "working late" technologique.

## CHARACTER REFERENCE

Archétype : CHAR-01 ou CHAR-03 (AI Consultant / Developer)
Pas de visage nécessaire — mains suffisent.

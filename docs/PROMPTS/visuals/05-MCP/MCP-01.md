# MCP-01 — MCP Hub Central

## OBJECTIVE

Représenter le Model Context Protocol comme un hub central connectant plusieurs systèmes.
L'image doit communiquer "orchestration" et "intelligence centrale" sans diagramme.

## USE CASE

- Hero visuel section MCP
- Feature "Connectez vos outils à votre IA"
- Page dédiée intégrations MCP

## PROMPT

```
aerial view of a single elevated central platform with radiating arms connecting
to smaller peripheral stations, dark matte surface, precision engineering,
cold blue light emanating from central hub downward, each arm conducting the light,
peripheral stations dimly lit, central unit bright and authoritative,
deep navy environment, industrial precision meets technology,
abstract spatial metaphor for orchestration,
no text labels, no app icons, purely structural,
architectural product photography, dark studio,
shot on Sony A7R V, 50mm overhead rig, f/8,
--ar 16:9 --style raw --v 7 --q 2
--no spoke-and-wheel cliche diagram, text labels, app icons, colorful elements, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas d'icônes d'applications reconnaissables
- Pas de labels texte
- La hiérarchie hub/périphérie doit être immédiatement lisible
- Pas de composition trop symétrique (paraît diagrammatique)

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[Hub central légèrement hors-centre (tiers droit)]
[4-6 bras rayonnant vers des noeuds périphériques]
[Vue overhead légèrement inclinée (≈ 30°)]
[Lumière principale sur hub, dégradant vers périphérie]
[Zone gauche : espace pour texte]
```

## COLOR DIRECTION

- Hub : Illuminé cold blue `#359BD9`
- Bras : Silver / anthracite
- Périphérie : Dark metal, LED indicators faibles
- Fond : `#05101E`

## CAMERA / LENS

Sony A7R V — 50mm — overhead légèrement incliné — f/8

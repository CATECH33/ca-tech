# MCP-03 — Tool Ecosystem

## OBJECTIVE

Représenter l'écosystème d'outils qu'un agent MCP peut utiliser.
Diversité d'outils, mais harmonie visuelle. L'IA choisit le bon outil.

## USE CASE

- Feature "Accès à tous vos outils depuis une IA"
- Section intégrations
- Slide "compatibilité"

## PROMPT

```
flat lay of minimal precision tools arranged in perfect grid on dark surface,
each tool a different abstract technical instrument (no specific brand tools),
cold studio light from above, each tool casting identical directional shadow,
perfect spacing between each element, museum-quality arrangement,
dark navy matte surface, tools in silver and dark metal,
negative space between tools is as important as the tools themselves,
editorial product photography for premium brand catalog,
shot on Sony A7R V, 50mm overhead, f/11,
--ar 3:2 --style raw --v 7 --q 2
--no app logos, software icons, phone, laptop, branded products, colorful tools, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas de logos de logiciels (HubSpot, Slack, Google...)
- Pas d'outils physiques reconnaissables (tournevis, marteau)
- Chaque outil doit être abstrait mais suggérer une fonction
- Espacement strict — pas de désordre

## ASPECT RATIO

`--ar 3:2` — 1200×800 px

## EXPECTED COMPOSITION

```
[Grille 3×4 ou 4×3 d'instruments]
[Espacement uniforme, alignement parfait]
[Vue overhead stricte]
[Ombres nettes identiques (même source lumineuse)]
[Fond Deep Navy]
```

## COLOR DIRECTION

- Outils : Silver mat / Dark Anthracite
- Fond : `#05101E`
- Éclairage : Cold white overhead

## CAMERA / LENS

Sony A7R V — 50mm — overhead strict — f/11

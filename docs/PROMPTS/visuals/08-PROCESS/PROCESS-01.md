# PROCESS-01 — Discovery

## OBJECTIVE

Première étape du processus CA-TECH : comprendre, écouter, analyser.
L'image représente l'attention portée au problème du client.

## USE CASE

- Section "Comment nous travaillons" étape 1
- Page A propos — processus
- Présentation commerciale

## VISUAL SERIES

Ces 6 images forment une série cohérente. Règles communes :
- Même palette Deep Navy / Cold Blue
- Même cadrage 3:2
- Même esthétique "hands & surfaces"
- Numérotation invisible mais séquence logique
- Chaque image peut se tenir seule mais raconte une étape

## PROMPT

```
two people sitting across each other at minimal dark conference table,
only the table surface and forearms visible, not faces,
one side has notebook and pen, other side has laptop edge visible,
body language: engaged, leaning slightly forward (attentiveness),
cold architectural light from above, deep shadow on table periphery,
premium minimalist meeting room, dark materials,
documentary photography aesthetic, natural moment not posed,
shot on Sony A7R V, 50mm, f/2.8,
--ar 3:2 --style raw --v 7 --q 2
--no faces smiling at camera, corporate handshake, whiteboard, colorful post-its, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas de visages regardant la caméra
- Pas de poignée de mains
- Pas de post-its colorés ou tableaux blancs
- La tension de l'écoute doit être dans la posture

## ASPECT RATIO

`--ar 3:2` — 1200×800 px

## COMPOSITION

Table sombre entre deux personnes — espace de dialogue suggéré.

## CHARACTER REFERENCE

CHAR-01 + CHAR-04 en opposition (consultant + entrepreneur)

# LLM-01 — Intelligence Core

## OBJECTIVE

Représenter le "cœur" d'un grand modèle de langage : une intelligence structurée, profonde,
abstraite. Pas un cerveau. Pas un server. Quelque chose de plus fondamental.

## USE CASE

- Visual hero de la page LLM / Modèles de langage
- Slide showcase "moteur IA"
- Feature highlight sur les capacités fondamentales

## PROMPT

```
extreme macro view of a single dark crystal with internal geometric light refraction,
cold blue and white light refracting through complex internal facets,
deep navy void background, crystal structure suspended and isolated,
microscopic precision in crystal edges, internal light paths visible,
scientific gemology photography aesthetic meets technology,
no human elements, no obvious tech references,
pure form and light intelligence metaphor,
shot on Sony A7R V, 200mm macro, f/8,
--ar 1:1 --style raw --v 7 --q 2
--no brain, neuron generic, circuit board, glowing orb cliche, purple, neon, colorful refraction
```

## NEGATIVE CONSTRAINTS

- Pas de cerveau ou neurone illustratif
- Pas d'orbe lumineux générique
- La réfraction de lumière doit rester dans la palette bleue-blanche
- Pas de fond coloré

## ASPECT RATIO

`--ar 1:1` — 1200×1200 px

## EXPECTED COMPOSITION

```
[Cristal centré, légèrement roté pour dynamisme]
[Fond : Deep Navy absolu]
[Lumière interne : chemins de réfraction bleus]
[Arrêtes nettes, intérieur complexe]
```

## COLOR DIRECTION

- Cristal : Dark steel + internal cold blue light
- Fond : `#05101E`
- Reflets : White + `#359BD9`

## CAMERA / LENS

Sony A7R V — 200mm macro — f/8 — ISO 400

## LIGHTING

Lumière interne seule. La lumière traverse le cristal, ne l'éclaire pas de l'extérieur.
Effet : intelligence vient de l'intérieur.

# LLM-05 — AI Reasoning Environment

## OBJECTIVE

L'espace mental d'un LLM en train de raisonner : structure, logique, connexions.
Représentation spatiale d'un processus invisible. Scientifique, précis, impressionnant.

## USE CASE

- Background section LLM / Raisonnement IA
- Showcase capabilities "Chain of thought"
- Page technique sur les modèles

## PROMPT

```
abstract three-dimensional geometric structure suspended in deep navy void,
precise wireframe of interconnected tetrahedra and nodes,
cold blue electric light tracing the edges only (not filled),
mathematical precision, crystalline geometry,
multiple nested structures at different scales creating depth,
scientific visualization aesthetic, not decorative,
no organic curves, pure geometric forms,
deep perspective, structures receding into deep background,
shot on Sony A7R V equivalent, 85mm, f/5.6, long exposure,
--ar 16:9 --style raw --v 7 --q 2
--no brain, neuron, atom, galaxy, colorful lights, neon, purple, organic, blob shapes
```

## NEGATIVE CONSTRAINTS

- Strictement géométrique — aucune forme organique
- Pas de neurones / synapses / cerveau
- Pas d'atome ou molécule (trop scientifique au sens chimie)
- La structure doit avoir une logique apparente (régularité mathématique)

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[Structure principale centrée]

[Deep Navy void autour]
[Lumière : uniquement les arêtes tracées en bleu]
```

- Structures : wireframe cold blue `#359BD9` sur fond `#05101E`

# LLM-02 — Context Processing

## OBJECTIVE

Représenter visuellement la "fenêtre de contexte" d'un LLM : la capacité à tenir compte
de grandes quantités d'informations simultanément. Profondeur, volume, structure.

## USE CASE

- Feature "Contexte étendu" / Long context
- Slide explication capacités LLM
- Illustration de la différence avec les chatbots basiques

## PROMPT

```
stacked layers of translucent dark glass panels, each slightly offset from the one above,
cold blue light filtering through the layers creating depth and transparency,
architectural abstraction suggesting information strata,
deep navy background, edges of glass panels catching cold light,
minimal dark studio, no reflections of environment,
scientific layering aesthetic, controlled precision,
no text, no UI, pure material abstraction,
shot on Sony A7R V, 85mm, f/5.6,
--ar 16:9 --style raw --v 7 --q 2
--no books, papers stacked, database cliche, colorful infographic layers, purple, neon
```

## NEGATIVE CONSTRAINTS

- Pas de livres ou papiers empilés (trop littéral)
- Pas de couches colorées type infographie
- La profondeur doit suggérer la quantité sans être écrasante
- Chaque couche doit rester distinguable

## ASPECT RATIO

`--ar 16:9` — 1920×1080 px

## EXPECTED COMPOSITION

```
[7-12 couches empilées, légèrement décalées en diagonale]
[Vue de trois-quarts pour sentir la profondeur]
[Lumière froide traversant depuis le fond]
[Zone avant/arrière floue, couches centrales nettes]
```

## COLOR DIRECTION

- Couches : Dark glass (semi-transparent, bleu-noir)
- Arêtes : Cold silver
- Lumière : `#359BD9` diffuse entre les couches

## CAMERA / LENS

Sony A7R V — 85mm — f/5.6 — ISO 400

## LIGHTING

Lumière traversante depuis le fond. Chaque couche filtre et atténue légèrement.
